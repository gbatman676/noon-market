# Noon Market
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

The UI is English-only. Customer Service -> Click Here opens https://t.me/customer_service_34.
BTC/USDT prices are fetched from CoinGecko through the server.

For a real production financial service, replace the local demo account/balance with secure server-side authentication and an auditable transaction ledger. Do not represent arbitrary admin balance changes as real funds.
